# JarvisClaw API Documentation

## Overview
The JarvisClaw Agent is an intelligent, high-performance assistant accessible via standard REST HTTP endpoints and real-time WebSockets. This system allows you to effortlessly integrate cutting-edge agentic capabilities into ANY web, mobile, or desktop application.

### Key Features
- **Any File Support**: Upload and receive processing for images, videos, audio/voice, and arbitrary documents.
- **Fast Streaming Responses**: Real-time generation streams tokens directly to your client without buffering, ensuring instant UI updates.
- **Model Agnostic**: Compatible with DeepSeek, OpenAI, Anthropic Claude (via OpenRouter/Proxy), and local models.
- **CORS Enabled**: Out-of-the-box support for browser-based frontend integration without proxy issues.

### Base URLs
**HTTP:** `http://<SERVER_IP>:20067/`
**WebSocket:** `ws://<SERVER_IP>:20067/ws`

## Configuration

Configure the agent by setting the following environment variables (or modifying `config.py`):

- `LLM_API_KEY`: Your model provider API key (defaults to `DEEPSEEK_API_KEY`).
- `LLM_BASE_URL`: The API endpoint (e.g., `https://api.openai.com/v1` or `https://openrouter.ai/api/v1`).
- `LLM_MODEL`: The model name (e.g., `gpt-4o`, `claude-3-5-sonnet`, `deepseek-chat`).

## REST Integration (For ANY App)

Using the new `/chat` endpoint is the easiest way to integrate the agent into simple HTTP applications.

### 1. Send Message (REST `/chat`)
**POST `/chat`**

Send a message and await the full final response. The API will also return a list of any files generated by the bot during its thought process.

**Request:**
```json
{
  "chat_id": "user_123",
  "message": "Draw me a chart of world population and send me the image."
}
```

**Response:**
```json
{
  "response": "Here is the chart you requested.",
  "bot_actions": [
    {"action": "send_photo", "filename": "chart_123.png"}
  ],
  "agent_states": [ ... array of intermediate thinking steps ... ]
}
```

### 2. Fetch Chat History
**GET `/history?chat_id=user_123`**

Returns the active history for a given chat.

**Response:**
```json
{
  "history": [
    {"role": "user", "content": "Hello!"},
    {"role": "assistant", "content": "Hello! How can I assist you today?"}
  ]
}
```

### 3. Upload Files
**POST `/upload`**

Upload images, audio files, or documents. Uses `multipart/form-data` with the file under the `file` key.

**Response:**
```json
{
  "filepath": "/full/path/to/downloads/file.txt",
  "filename": "file.txt"
}
```
*Note: You can reference `[File: /full/path...]` or `[Voice: /full/path...]` in your chat messages.*

## Real-Time WebSocket API (For Advanced Streaming)

For an ultra-responsive UI, connect via WebSocket and listen to the agent's internal thought process and streaming tokens.

**WS `/ws`**

### Sending a Message
```json
{
  "action": "chat",
  "chat_id": "user_123",
  "message": "Write a python script to reverse a string."
}
```

### Receiving State Updates
The server streams state back as the agent works:

```json
{
  "type": "agent_state",
  "data": {
    "status": "final_stream",
    "content": "Here is "
  }
}
```

**Status Types:**
- `thinking`: Agent has started planning.
- `thinking_stream`: Stream of agent's internal logic.
- `tool_use`: Agent invoked a tool (has `tool` and `args` properties).
- `observation`: The result of the tool execution.
- `final_stream`: Fast stream of the final textual response back to the user.
- `final`: The fully complete final response.

### Receiving Bot Actions (Files/Media)
If the agent creates a file, video, or image, the WebSocket sends a `bot_action` event:

```json
{
  "type": "bot_action",
  "action": "send_video",
  "chat_id": "user_123",
  "filename": "generated_video.mp4"
}
```
**Supported Actions:** `send_message`, `send_document`, `send_photo`, `send_video`, `send_audio`, `send_voice`, `send_file`.

*(You can then download these files via `GET /download/generated_video.mp4`)*
